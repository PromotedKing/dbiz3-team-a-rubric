# Where the spec lives

This repository uses the Session 4 layout: there is no single `docs/spec/spec-document.md`. The Spec Documents are one file per module in `specs/`:

| Module | File |
|---|---|
| ACC — Onboarding & Session | `specs/spec-ACC.md` |
| HLT — Health Visibility (Dashboard) | `specs/spec-HLT.md` |
| ALR — Risk Feedback & Mom Alert | `specs/spec-ALR.md` |
| CLI — Clinical Escalation (Nurse + Doctor) | `specs/spec-CLI.md` |
| TML — Pregnancy Timeline & Diary | `specs/spec-TML.md` |
| BOT — AI Chatbot L1 Support | `specs/spec-BOT.md` |
| APT — Appointment (redirect to host app) | `specs/spec-APT.md` |

The entity list for all modules is `data/data-model-MB360.md` §2. For the Session 6 T3 read-back prompt adapted to this layout, see `docs/env/readiness-report.md` §3.
